## Resource accounting and failure

Both protocols used two intra-op/BLAS threads, one inter-op thread, a sampled 3 GiB combined RSS limit, 1200-second wall limit, and a 1195 child-CPU-second stop threshold inside a 1200-second CPU envelope. Sampling is not continuous observation or a guarantee of zero overshoot.

The bounded run's last CPU sample was 1195.20 seconds. It retained 326 updates (836.68 CPU seconds) and three evaluations (354.03 CPU seconds). Closure's last valid CPU sample was 1105.48 seconds, **additional** to the original run, about 2300.68 sampled CPU seconds total. Closure training used 991.60 CPU seconds, validation LM 21.22, and generations 87.59; overhead is not included in these phase totals.

Closure's last valid telemetry sample was at 557.684785578 elapsed seconds. An accounting failure followed at 557.785855675 seconds with `Missing, duplicate or malformed VmRSS accounting`; summary wall time was 557.801696608 seconds. Peak sampled combined RSS was 1,519,984,640 bytes (about 1.416 GiB). Worker status records 384 updates and 48 generations, returncode 0, beneath the supervisor's incomplete status.

This is consistent with an exit/accounting race but does not prove one. The failing PID, raw accounting text, and exact intervening poll/kill sequence were not retained. No clean monitored shutdown or exact terminal CPU measurement is claimed. No frozen artifact was backpatched and no new training or inference was used for the publication audit.

## Interpretation and limits

At full parse coverage, correctness improved 24→39→46 and jointly correct groups 8→11→15. This supports a budget/exposure limitation of the 24-update control on this task. Consistency was non-monotonic: answer changes 0→4→1, so final consistency does not beat step 24. A consistently wrong answer is not factual success. A zero strict score with zero parser coverage does not prove absent semantic competence.

One seed, synthetic templates, correlated variants, reused development validation and repeated training prevent claims of statistical significance, broad generalization, convergence or a plateau. This is not a test-set result, auxiliary-head benefit, human-comprehension result, accessibility result, natural-language transfer result or model-wide conclusion.

## Package and reproducibility

This is an explicitly labeled **public derivative**, not the original execution archive. Scientific code/data and numerical arrays are preserved; local model paths and CLI help are made portable. Original coordination prose, revision history prose and autogenerated placeholder model cards are omitted. Each study's `DERIVATION.json` maps original to public SHA-256 values or records omissions; `SOURCE-IDENTITY.json` records the original frozen source hash and file hashes.
